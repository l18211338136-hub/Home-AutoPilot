## 本机构建验证（Windows / MSVC 19.51 / CMake 4.3 / Ninja）

- 本机没有独立 gcc/cmake/ninja，使用 VS 18 Enterprise 自带工具链；`tools/build_windows_native.bat` 调 `vcvars64.bat` 后执行 CMake+Ninja+CTest。
- 坑：沙箱拦截 `reg.exe` 导致 vcvars 未设置 Windows SDK 路径 → 先报 `rc.exe` 找不到，再报 `LNK1104 kernel32.lib`。解决：脚本里动态探测 MSVC/SDK 版本，**显式设置 `INCLUDE`/`LIB`/SDK bin PATH**（`%ProgramFiles(x86)%` 不能写在 `if (...)` 块内，括号会破坏 cmd 解析）。
- 坑：`simulation/` 与 `test/` 的头文件用 `simulation/xxx.hpp` 形式引用，根 CMake 只把 `src/` 加进 include 根会编译失败 → 需要同时把项目根加入 `homefly_include` 的 INTERFACE include 目录。
- 结果：42/42 编译目标通过，8/8 CTest 通过；正常场景初始 roll 11.54°/pitch -6.87° 收敛到 ±0.3° `PASS`；IMU 掉线场景进入 Failsafe+ImuReadFault+电机归零 `PASS`。
